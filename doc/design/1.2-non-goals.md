# 1.2 Non-Goals

[Architecture documentation](README.md) >
[1. Architecture Overview](1-architecture-overview.md)

The architecture deliberately excludes:

- Firmware boot, caller-defined ACPI and SMBIOS tables or device trees, PCI, vPCI, VMBus, and
  arbitrary devices.
- SMT, multiple NUMA nodes, non-x86 guests, and nested virtualization.
- General CPU or memory hotplug after readiness.
- Restore across hypervisor backends or CPU generations, live migration, and
  capture-and-continue.
- Scaling of the TSC, trapping of RDTSC, paravirtual clocks, and a virtual PMU.
- Serialization of live network flows, native host handles, or the contents of
  a live host filesystem export.
- Multi-container orchestration, including pod infrastructure, pause
  containers, dynamic root filesystem injection, and host calls that create
  additional containers.
- Confidential computing, because the host is trusted with image content and
  guest memory.
- Tenant authorization inside the VMM.
